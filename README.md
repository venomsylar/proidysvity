# Пройдисвіти

Весела 3D-настільна гра про похід у підземелля: вибиваєш двері, бʼєш монстрів, збираєш скарби, підставляєш друзів — і першим доходиш до 10-го (або 20-го) рівня. Натхненна класичними «манчкінськими» настолками, але всі карти, тексти й малюнки — свої.

**Грати:** https://venomsylar.github.io/proidysvity/

## Можливості

- 3D-стіл з анімаціями карт і кубика, 5 скінів стола: Таверна, Новорічний, Лампова ніч, Підземелля, Космос.
- Гра з ботами трьох рівнів складності (боти памʼятають образи й торгуються).
- Кілька людей за одним пристроєм — чужі карти приховано.
- Гра з різних пристроїв по мережі: господар створює кімнату, інші вводять код.
- Звичайна гра до 10 рівня або епічна до 20.
- Раси, класи, стать, прокляття, мертвяки, бої з кількома монстрами, торг за допомогу, обмін речами.
- Нежить і дракони — вмикаються на старті за бажанням; вогняні речі палять нежить, але не діють на драконів, а для драконів є драконобійна зброя.
- Разові карти, що додають силу або віднімають її в монстра чи суперника.
- Звукові ефекти й своя музика для кожного стола (окремі гучності, вимкнення клавішею M).
- Номер версії біля назви гри — натисни, щоб побачити список змін.

## Як запустити

- **В інтернеті:** відкрий посилання вище (працює на iPhone, iPad, Android, компʼютері).
- **Локально:** відкрий `index.html` у браузері на компʼютері. Потрібен інтернет: 3D-рушій, шрифти й мережева гра завантажуються з CDN.

На iPhone/iPad файл з «Файлів» не запуститься — відкривай через посилання. Щоб гра була як застосунок: Safari → «Поділитися» → «На екран „Додому“».

## Будова проєкту

```
index.html        розмітка сторінки й підключення файлів
css/style.css     увесь вигляд інтерфейсу
js/version.js     номер версії і список змін (показується в грі)
js/utils.js       дрібні допоміжні функції
js/cards.js       усі карти: монстри, скарби, прокляття, раси, класи
js/state.js       стан гри, сила гравців, налаштування ботів
js/scene3d.js     3D-сцена: стіл, карти, камера, скіни
js/sound.js       синтезовані звуки й музика (без аудіофайлів)
js/game.js        перебіг ходу: двері, бій, втеча, допомога, обмін
js/actions.js     єдина система дій для людей, ботів і мережі
js/net.js         гра по мережі (PeerJS)
js/ui.js          панелі, рука, табло, вікна
js/main.js        версія в інтерфейсі й запуск гри
```

Збірки немає: це звичайні скрипти, які браузер завантажує по черзі (порядок важливий — він задається в `index.html`).

Сторонні бібліотеки підтягуються з CDN: [three.js r128](https://threejs.org/) (3D) і [PeerJS 1.5.4](https://peerjs.com/) (мережа).

## Як випустити нову версію

1. Внести зміни.
2. У `js/version.js` збільшити `APP_VERSION` і додати запис на початок `CHANGELOG`.
3. В `index.html` замінити `?v=…` біля всіх файлів на новий номер — тоді телефони не візьмуть старі файли з кешу.
4. Відправити на GitHub:
   ```
   git add .
   git commit -m "v17: що змінилося"
   git push
   ```
   За хвилину GitHub Pages оновить сайт.

У мережевій грі всі гравці мають бути на одній версії — якщо ні, гра попросить оновити сторінку.
